## Release Branch: v2 (Basic Auth)

This is the `release/v2` branch — the stable basic-auth version of the LAMP Dashboard. It is pinned to `lamp-core@2024.10.16` (LAMP-js `v2.0.0`).

| Dependency | Version | Corresponds to |
|-----------|---------|---------------|
| `lamp-core` | `2024.10.16` | LAMP-js `release/v2` / `v2.0.0` |

This branch receives critical and security fixes only. For the latest features (session auth, OAuth, 2FA), see the `master` branch or `release/v3` when available.
